# One shared runtime: upstream integration and peer communication

## Owner purpose and the corrected finish line

Kestrel clarified that there is one Codex Desktop runtime in operation, the one
Coordinator uses. The intended task includes improving inter-instance
communication inside that shared setup and updating the runtime at the same
time. The separately landed Ath memory-delegate kit (Ath2067/PR46) is useful
coordination, not completion of the native work. Technical separability did not
authorize deferring this requested capability. Ath2070 preserves that correction
and the bounded assumption-control lesson.

No second deployed app-server or separately hosted model is a prerequisite.
Development worktrees/build processes are source tooling, not another resident
runtime. Keep the80GiB free-disk floor, two build jobs and disabled incremental
compilation. No live settings/credentials, installation, selector change or
restart happens merely because this source task starts.

   delegated-input compaction, digest-bound history/source recovery, deliberate
   authority/review modes, literal argv/shell behavior, media/tool delivery and
   current Desktop/Remote contracts. Do not equate marker-free with compatible.

   Reuse existing typed inter-agent input and turn lifecycle mechanics; keep
   active steering, queue-only delivery, idle wake and cold restore distinct.
   Bind sender/target/grants through the host, not self-asserted model labels.
   The existing app/tool route remains a valid comparator and fallback only
   where explicitly chosen, never silent authority or lifecycle substitution.
3. Regenerate affected schemas; scoped lint/fmt and focused native integration
   checks. Exercise two independent authorized roots, valid active/idle/cold
   transitions as implemented, refusals, changed grants, cancellation, duplicate
   correlation and attributed return. Retain child/root restrictions.
4. Build one immutable package with source provenance. Qualify copied-database
   migrations/recovery and development-lane checks without touching live data.
5. Present the exact installation/restart boundary before disrupting the running
   session. Actual package pickup and Desktop/phone communication need their
   own observed receipt; source tests do not establish those.

the additional source review accepted this bounded envelope, not an unbounded
context item or measured optimum.
