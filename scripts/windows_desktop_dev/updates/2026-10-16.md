# One shared runtime: upstream integration and peer communication

## Owner purpose and the corrected finish line

Kestrel clarified that there is one Codex Desktop runtime in operation, the one
Coordinator uses. The intended task includes improving inter-instance
communication inside that shared setup and updating the runtime at the same
time. The separately landed Ath memory-delegate kit (Ath2067/PR46) is useful
coordination, not completion of the native work. Technical separability did not
authorize deferring this requested capability. Ath2070 preserves that correction
and the bounded assumption-control lesson.

No second deployed app-server or separately hosted model is a prerequisite.
Development worktrees/build processes are source tooling, not another resident
runtime. Keep the80GiB free-disk floor, two build jobs and disabled incremental
compilation. No live settings/credentials, installation, selector change or
restart happens merely because this source task starts.
